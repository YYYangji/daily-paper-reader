## 摘要
语言引导的无人机代理必须执行长程语义指令，同时生成平滑、物理可行的连续飞行命令，然而现有的视觉语言导航（VLN）基准通常使用离散或粗粒度的动作，现有的无人机视觉-语言-动作（VLA）任务则侧重于短时的原子操作。为填补无人机任务设置中的这一空白，我们引入了\textbf{FLIGHT}，一个用于混合无人机导航与推理任务的\textbf{细粒度长程指令引导基准}，它结合了多阶段指令与密集的6-DoF轨迹标注，包含两个数据集分割：细粒度VLN和长程流。为使无人机代理具备对任务执行状态与任务规划的实时飞行中推理能力，同时适应高频实时精确控制，我们进一步提出了\textbf{FLIGHT VLA}，一种异步架构，将用于任务状态推理的低频流式飞行员视觉语言模型（VLM）与用于连续控制的高频扩散动作模型解耦，并由显式的\textbf{飞行员推理}文本进行监督，该文本总结当前飞行状态并预测下一个子目标。在闭环评估中，FLIGHT VLA在我们的FLIGHT基准上持续超越代表性的VLN和VLA基线，实现了更强的多阶段完成、子目标遵循和终端控制。其训练后的流式飞行员推理VLM进一步提升了无人机视频推理，验证了我们设计的有效性。

## Abstract
Language-guided UAV agents must execute long-horizon semantic instructions while producing smooth, physically feasible continuous flight commands, yet existing Vision-Language Navigation (VLN) benchmarks typically use discrete or coarse actions and existing UAV Vision-Language-Action (VLA) tasks focus on short, atomic maneuvers. To address this gap in UAV task settings, we introduce \textbf{FLIGHT}, a \textbf{F}ine-grained \textbf{L}ong-horizon \textbf{I}nstruction-\textbf{G}uided benchmark for \textbf{H}ybrid UAV navigation and reasoning \textbf{T}asks, which combines multi-stage instructions with dense 6-DoF trajectory annotations across two dataset splits: Fine-grained VLN and Long-horizon Flow. To endow the UAV agent with the capability of real-time in-flight reasoning over task execution status and mission planning, while simultaneously accommodating high-frequency, real-time precise control, we further propose \textbf{FLIGHT VLA}, an asynchronous architecture that decouples a low-frequency Streaming Pilot Vision-Language Model (VLM) for task-state reasoning from a high-frequency diffusion action model for continuous control, supervised by explicit \textbf{Pilot Reasoning} texts that summarize the current flight state and anticipate the next subgoal. In closed-loop evaluation, FLIGHT VLA consistently surpasses representative VLN and VLA baselines on our FLIGHT benchmarks, achieving stronger multi-stage completion, subgoal adherence, and terminal control. Its trained Streaming Pilot Reasoning VLM further improves UAV video reasoning, validating the effectiveness of our design.

- 现有无人机语言导航任务存在两大缺陷：
  - **VLN基准**（如Aerial VLN、OpenFly）通常采用离散动作或稀疏的路径点，无法表征真实无人机飞行的连续轨迹和3D运动学约束。

- 实际无人机任务（如“飞过两个街区，在路口左转，悬停在邮箱旁投递，最后降落在第二个邮箱旁边”）既需要长程多阶段语义理解，又需要在每个阶段生成精确、平滑、物理可行的连续控制指令。
- 为此，论文提出了**FLIGHT基准**（细粒度长程指令引导的混合导航推理任务）和**FLIGHT VLA异步架构**，旨在弥合高层语义规划与低层连续控制之间的鸿沟。

## 2. 方法论：核心思想与关键技术细节

### 2.1 FLIGHT基准设计
- 包含两个子任务：
  - **Long-horizon Flow**：将单阶段原子动作扩展为多阶段组合任务（如“先从左绕过第一棵树，再从右绕过第二棵树，然后接近第三棵树”）。
  - **Fine-grained VLN**：在传统VLN基础上，提供更密集的文本指令（每100米动词数6.23 vs. 2.17、名词12.26 vs. 3.25）和连续动作空间（每100米动作步数295.45 vs. 30.86）。
- **Pilot Reasoning机制**：人工飞行员在关键节点显式输出当前状态分析和下一步行动意图的文本（如“State: Reach the intersection. Next: Turn left at the intersection.”），作为“认知锚点”连接高层指令与低层控制。

### 2.2 FLIGHT VLA异步架构
- 核心思想：解耦**低频语义推理模块**（Streaming Pilot VLM）与**高频动作生成模块**（Diffusion Action Model），两者异步工作。

#### Streaming Pilot VLM（低频，~0.5–1 Hz）
- 基于StreamingVLM架构，输入任务指令、近期视频窗口和推理历史记忆，输出Pilot Reasoning文本和语义隐特征\(z_\tau\)。
- 使用重叠块全注意力训练，保持时序一致性。
- 输出文本（状态+下一步动作）写回记忆，形成紧凑的长期上下文。

#### Diffusion Action Model（高频，~10–30 Hz）
- 接收当前帧、UAV状态和最新的语义特征\(z_{\tau(t)}\)（可能滞后于当前时刻）。
- 使用独立的ViT编码当前帧，避免复用VLM的低频视觉特征。
- 采用Diffusion Transformer（DiT-B）生成未来\(H\)步的连续动作序列（相对位移和姿态变化），通过Flow Matching目标训练。
- 动作序列预测机制允许VLM推理期间控制器仍能获取有效指令，消除控制间隙。

#### 异步延迟训练对齐
- 在训练时模拟VLM语义特征到达的不同延迟（如1s、3s），让动作模型学会利用当前视觉和相对位姿补偿滞后，增强对推理延迟的鲁棒性。

#### 联合训练
- 损失：\(\mathcal{L} = \lambda_{\text{vlm}}\mathcal{L}_{\text{vlm}} + \lambda_{\text{act}}\mathcal{L}_{\text{act}}\)，其中\(\lambda_{\text{vlm}}=0.1\)。
- 两阶段训练：先联合优化，再冻结VLM单独训练动作模型以提高控制精度。

## 3. 实验设计

### 3.1 数据集
- **FLIGHT数据集**：基于Unrealzoo仿真环境（城市、工业、乡村场景），由人类飞行员和少量路径规划模型采集。
  - Fine-grained VLN：6689条轨迹，平均长度154.5 m，每轨迹平均475个连续动作（10 Hz采样）。
  - Long-horizon Flow：4098条轨迹，平均3.37个动作实例，平均路径长度32.8 m。
- 每个轨迹配有密集6-DoF位姿、FPV视频、VLM辅助生成的语义标签和Pilot Reasoning文本。

### 3.2 基准与对比方法
- **Long-horizon Flow任务**：
  - VLA基线：OpenVLA-UAV（离散化动作空间）、Memory VLA（引入记忆模块）。
  - 指标：Success Rate (SR), Stage Success Rate (SSR), Normalized DTW (NDTW)。
- **Fine-grained VLN任务**：
  - VLN基线：CMA+LAG（跨模态注意力+前瞻引导）、NaVid（视频基VLM直接生成推理并映射为动作）。
  - 指标：SR, Oracle SR (OSR), Navigation Error (NE), Instruction Adherence Success Rate (IASR)。
- **VLM推理准确性评估**：对比Gemini-3-flash、Qwen 3.6 plus、Qwen 2.5 VL 3B（未训练）与本文训练的Streaming Pilot Reasoning VLM，在VLN视频-文本序列上评估State Accuracy和Action Accuracy。

## 6. 主要结论与发现

- 现有VLN和VLA基线在长程细粒度无人机任务中表现不佳，主要原因是缺乏连续的长期上下文保持和连续控制能力。
- **FLIGHT VLA显著优于所有基线**：
  - Long-horizon Flow上：SR 59.0%（vs Memory VLA 18.5%、OpenVLA-UAV 10.5%）。
  - Fine-grained VLN上：IASR 11.0%（vs NaVid 5.0%、CMA+LAG 4.5%），SR和OSR也领先。

- 异步快-慢架构有效平衡了长程语义理解与实时控制，Pilot Reasoning文本提供了关键的任务状态追踪和规划信息。

## 7. 优点（方法或实验设计亮点）

- **任务创新**：首个将长程多阶段指令与连续6-DoF控制结合的无人机导航基准，填补了VLN和VLA之间的空白。
- **Pilot Reasoning机制**：显式外部化决策链，作为“认知锚点”，既用于监督训练又用于VLM推理，可解释性强。
- **异步架构**：巧妙解耦低频推理与高频控制，训练时模拟延迟增强鲁棒性，实际部署时允许VLM推理滞后而不中断控制。
