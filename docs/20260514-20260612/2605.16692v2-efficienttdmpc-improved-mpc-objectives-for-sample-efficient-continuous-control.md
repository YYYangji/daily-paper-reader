## 摘要
我们提出了EfficientTDMPC，一种基于TD-MPC算法族的样本高效模型强化学习方法，用于连续控制。该算法族的核⼼是⼀个规划器，旨在寻找最大化估计回报的动作序列。回报通过学习的模型和值网络估计，每个部分都可能引入误差。EfficientTDMPC通过两种方式减少误差：⾸先，引入了动力学模型集成，并在不同模型和不同展开深度上平均回报估计；其次，增加了对规划器目标应用不确定性惩罚的选项，使规划器避免选择具有不确定回报估计的动作。此外，我们增加了实际改进措施，提升了缓冲区数据新鲜度并降低了计算量。最后，我们发现这些贡献使EfficientTDMPC能够从更⾼的更新-数据比（UTD）中受益，进⼀步提⾼样本效率。据我们所知，在每个基准的低数据条件下，EfficientTDMPC在HumanoidBench-Hard和DMC hard上实现了样本效率的最先进水平（SOTA），同时在DMC easy上达到了SOTA。

## Abstract
We introduce EfficientTDMPC, a sample-efficient model-based reinforcement learning method for continuous control built on the TD-MPC family of algorithms. Central to this family is a planner that aims to find an action sequence that maximizes the estimated return. The return is estimated using a learned model and value networks, each of which can introduce error. EfficientTDMPC proposes to reduce this error in two ways. First, it introduces an ensemble of dynamics models and averages the return estimates across those models and across different rollout depths. Second, it adds the option to apply an uncertainty penalty to the planner objective, yielding a planner that avoids actions with uncertain return estimates. It then adds practical improvements which increase buffer data freshness and reduce compute. Lastly, we find that our contributions enable EfficientTDMPC to benefit more from a higher update-to-data (UTD) ratio, further improving sample efficiency. To the best of our knowledge, in the low data regime of each benchmark, EfficientTDMPC achieves state-of-the-art (SOTA) in terms of sample efficiency on HumanoidBench-Hard and DMC hard, while matching SOTA on DMC easy.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：基于模型的强化学习（MBRL）通过学习世界模型并用于规划，在连续控制任务中取得了较高的样本效率。TD-MPC 系列（如 TD-MPC2、BMPC）在其中表现突出，其核心是一个 MPC 规划器，通过优化动作序列最大化估计回报。
- **核心问题**：规划器使用的回报估计依赖于学习的动力学模型、奖励模型和价值网络，这些组件都会引入误差。当模型不准确时，规划器会利用这些误差找到“看起来好”但实际不优的动作序列，导致样本效率下降。
- **动机**：现有方法（如 BMPC）依赖单一动力学模型，且未显式处理规划目标中的不确定性。本文旨在通过改进规划目标，降低估计误差，提升样本效率。

## 2. 方法论：核心思想、关键技术细节

### 核心思想
通过三个方面降低规划目标中的误差：
1. **动力学模型集成**：使用多个动力学头对回报进行平均估计，降低单一模型误差。
2. **多深度回报聚合**：在不同展开深度上对回报估计取平均，降低方差。
3. **悲观重分析**：在重分析（reanalyze）时对规划目标添加不确定性惩罚，避免选择估计值不确定的动作。

此外，还有实用改进：每步插入经验（提升数据新鲜度）、降低重分析计算量、适配更高的更新-数据比（UTD）。

### 关键技术细节

- **动力学集成**：使用 \(N_f\) 个动力学头 \(f_{\theta,i}\) 和 \(N_v\) 个值头 \(V_{\theta,j}\)，对每个 (i, j) 组合计算回报估计 \(\hat{Q}^\pi_H(z_t, a_{t:t+H-1}; i, j)\)，然后取平均：
  \[
  \hat{Q}^\pi_H(z_t, a_{t:t+H-1}) = \frac{1}{N_f N_v} \sum_{i=1}^{N_f} \sum_{j=1}^{N_v} \hat{Q}^\pi_H(z_t, a_{t:t+H-1}; i, j)
  \]
  同时计算方差估计 \(\hat{\sigma}^2_{\hat{Q}^\pi_H}\) 用于下一步的悲观惩罚。

- **多深度聚合**：将不同展开深度 \(h=1..H\) 的回报估计取平均：
  \[
  \hat{Q}_{\text{aggregate}, H}(z_t, a_{t:t+H-1}) = \frac{1}{H} \sum_{h=1}^{H} \hat{Q}_h(z_t, a_{t:t+h-1})
  \]
  该目标在动作执行规划（acting planner）中使用，并增加规划展开深度（从 3 到 6）。

- **悲观重分析**：在重分析优化目标中加入不确定性惩罚项：
  \[
  J_{\text{reanalyze}, H}(a_{t:t+H-1}) = \hat{Q}^\pi_H(z_t, a_{t:t+H-1}) - \beta \, \hat{\sigma}_{\hat{Q}^\pi_H}(z_t, a_{t:t+H-1})
  \]
  其中 \(\beta\) 为悲观系数，在 HumanoidBench 上设为 10，在 DMC 上设为 0。

- **实用改进**：
  - 每步立即插入经验，而非每回合后插入。
  - 重分析时减少 MPPI 粒子数、精英数等（从 512 降到 64），降低计算量。
  - 提升 UTD 比例（从 1 到 2 或 4），同时增加重分析频率。

### 算法流程（文字说明）
1. 与环境交互，收集经验 \((s, a, r, s')\) 并立即存入回放缓冲区。
2. 以一定频率从缓冲区采样，用集成动力学模型、奖励模型、值网络更新模型参数。
3. 在动作执行时，使用聚合多深度目标进行 MPPI 规划，输出动作分布并采样执行。
4. 在重分析时，对缓冲区中旧状态使用简化规划（低粒子数）并添加悲观惩罚，得到策略目标，蒸馏策略网络。
5. 根据 UTD 比例重复多步模型更新。

## 6. 主要结论与发现

- **样本效率**：在 HumanoidBench-Hard 和 DMC hard 上，EfficientTDMPC 达到 SOTA 样本效率（归一化 AUC 最高）；在 DMC easy 上匹配 SOTA（与 BMPC 等相当）。
- **组件有效性**：动力学集成、深度聚合、实时插入每步经验均对性能有正向贡献（组合后更显著）；悲观惩罚在 HumanoidBench 上有效，但在 DMC 上可能有害。
- **UTD 缩放**：EfficientTDMPC 比 BMPC 更能从更高的 UTD 中受益，尤其在高维任务上。
- **重分析计算降低**：减少 8 倍规划粒子不影响性能，从而节省大量训练时间。
- **规划器误差分析**：通过交叉评分实验（附录 C.1）表明，集成平均能有效防止规划器利用单一模型的偏差，使规划的动作更可靠。
