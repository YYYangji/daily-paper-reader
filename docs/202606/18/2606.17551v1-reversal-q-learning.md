## 摘要
迭代生成建模技术（如流匹配）为建模复杂行为提供了强大工具，可有效实现离线强化学习。本文提出一种基于先验数据训练流策略的新型离策略强化学习算法。我们的想法源于“扩展”马尔可夫决策过程框架，该框架将流细化步骤视为马尔可夫决策过程中的独立动作。为了在该框架内实现离策略强化学习，我们应用了两种技术：通过“反向”流生成虚拟在线轨迹，使该框架与先验数据兼容；并应用偏差-方差缩减技术来缓解离策略强化学习中的视野诅咒。我们将由此产生的算法称为反向Q学习。与以往的基于流的强化学习方法相比，反向Q学习具有多项优势：无需经历时间反向传播，能更好地利用学习到的价值函数，并直接训练完整且富有表现力的流策略。通过在50个具有挑战性的模拟机器人任务上的实验，我们表明，与最先进的基于流的离线强化学习算法相比，反向Q学习实现了最佳的平均离线强化学习性能。

## Abstract
Iterative generative modeling techniques, such as flow matching, provide powerful tools to model complex behaviors for effective offline reinforcement learning (RL). In this work, we propose a new off-policy RL algorithm that trains a flow policy based on prior data. Our idea starts from the "expanded" Markov decision process (MDP) framework, which treats individual flow refinement steps as separate actions in an MDP. To enable off-policy RL within this framework, we apply two techniques: we generate virtual on-policy trajectories (by "reversing" flows) to make this framework compatible with prior data, and we apply a bias-and-variance reduction technique to mitigate the curse of horizon in off-policy RL. We call the resulting algorithm Reversal Q-learning (RQL). RQL has several advantages over previous flow-based RL methods: it does not suffer from backpropagation through time, makes better use of the learned value function, and directly trains the full, expressive flow policy. Through our experiments on 50 challenging simulated robotic tasks, we show that RQL leads to the best average offline RL performance compared to state-of-the-art flow-based offline RL algorithms.

### 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：离线强化学习（offline RL）旨在从静态数据集中学习最优策略。近年来，迭代生成模型（如扩散模型、流匹配）被用于建模复杂的行为分布（称为“流策略”），但将其与强化学习结合面临两大难题：
  1. **时间反向传播（BPTT）不稳定**：直接对迭代过程进行梯度回传会导致训练不稳定和性能下降。
  2. **现有方法的局限性**：回归方法（加权回归、拒绝采样）只使用零阶价值信息，效率低；蒸馏方法需要额外计算；扩展MDP框架在离策略场景中因缺乏完整流轨迹且视野过长（“诅咒 of horizon”）而难以直接应用。
- **研究背景**：已有工作（如DPOK、DPPO）将扩散步骤视为一个扩展MDP的动作，并在在线策略RL中取得成功，但离线场景下需要解决数据缺失和视野诅咒。

### 论文提出的方法论

- **核心思想**：基于扩展MDP框架，将流策略的每个欧拉积分步骤视为独立动作；利用流匹配的**确定性**和**可逆性**，通过**反转流**从离线数据集中的状态-动作对重构出当前策略下的完整流轨迹（虚拟在线轨迹）；再对这些虚拟轨迹应用**多步回报**，有效缩短价值学习的视野，避免偏差和方差。
- **关键技术细节**：
  1. **扩展MDP**：将原MDP的状态 `(s, a, r, s')` 扩展为 `(s, x, f)`，其中 `x` 是部分生成的动作，`f` 是流时间步。每个动作是速度场 `v(s, x_f, f)`，每F步与环境交互一次。
  2. **反转流生成虚拟轨迹**：对数据集中的每个 `(s, a)`，通过反向ODE `x_{f-1} = x_f - v(s, x_f, f)` 从 `x_F = a` 反推至 `x_0`，得到完整流序列。
  3. **多步Q学习（价值视野缩减）**：直接使用整个流轨迹的累积回报作为TD目标，仅保留原始MDP步的折扣，中间流步使用γ=1。由于虚拟轨迹是确定且在线策略的，多步回报无偏且零方差。
  4. **实用算法（RQL）**：
     - 值函数训练：采用类似IQL的期望分位数回归损失 `L(V) = E[ℓ_κ²(V - (r + γV'))]`，隐式近似max操作。
     - 策略训练：DDPG风格损失 `L(v) = -E[V(s, x_f+v, f+1)] + α L_BC(v)`，其中 `L_BC` 为行为克隆损失，平衡价值最大化与数据先验。
- **算法流程**（文字说明）：
  - 从经验回放缓冲区采样 `(s,a,r,s')`；
  - 通过当前流策略的反转求 `x_0...x_F`，构造虚拟轨迹 `τ̃`；
  - 训练值函数 `V`（每个流状态）最小化期望分位数损失；
  - 训练流策略 `v` 最小化价值引导加行为正则化损失。
