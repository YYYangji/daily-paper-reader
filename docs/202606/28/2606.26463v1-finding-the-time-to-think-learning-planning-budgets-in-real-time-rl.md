## 摘要
深思熟虑需要时间。在实时环境中，时间不是免费的。标准强化学习（RL）回避了这个问题，因为环境会无限期等待智能体的决策。相反，我们研究实时强化学习环境，在这种环境中，环境在等待智能体动作的同时会继续推进。基于先前的实时形式化模型，我们引入了变延迟实时强化学习，其中智能体在每个决策点选择思考多长时间，因为环境在不断推进。对于我们所使用的规划智能体，正确的延迟是状态依赖的，而简单地规划要思考多久可能会使智能体瘫痪。相反，我们通过在规划器之上训练一个轻量级的门控策略来选择状态依赖的规划预算。在实时吃豆人、俄罗斯方块、贪吃蛇、极速六角棋和极速围棋中，我们的门控策略优于固定预算和启发式基线，并且能够迁移到环境和智能体在两个不同GPU上运行的实时设置中。

## Abstract
Deliberating takes time. In real-time settings, that time is not free. Standard reinforcement learning (RL) sidesteps this as the environment waits indefinitely for the agent's decision. Instead, we study real-time RL environments where the environment progresses while waiting for the agent's action. Building on prior real-time formalizations, we introduce variable-delay real-time RL, where the agent chooses how long to deliberate at each decision point since the environment progresses. For the planning agents we use, the right delay is state-dependent, and naively planning how long to plan can paralyze the agent. We instead approach this setting by training a lightweight gating policy on top of a planner to select state-dependent planning budgets. Across real-time Pac-Man, Tetris, Snake, Speed Hex, and Speed Go, our gating policy outperforms fixed-budget and heuristic baselines, and transfers to a real-time setup where the environment and agent run on two different GPUs.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：在实时强化学习环境中，标准 MDP 假设环境会无限期等待智能体的决策，但现实世界的实时决策需要代价——环境在执行期间持续推进。本文聚焦于如何在“计划需要时间、时间不可免费”的设定下，让智能体**自适应地分配规划计算资源**（即选择思考多久），平衡规划质量与时间成本。
- **背景**：现有工作如 Ramstedt & Pal (2019) 形式化了单步固定延迟的实时 RL，但智能体无法自主调节思考时间。而可伸缩规划算法（如 MCTS）的规划质量随模拟次数单调提升，但延迟也线性增长。因此，需要**状态依赖的规划预算分配**，避免简单的“规划多久”元推理陷入悖论。
- **整体含义**：提出**变延迟实时 RL** 框架，将计算时间视为环境推进的代价，让智能体通过学习控制规划预算，实现“在正确的时间投入正确的计算量”，从而提高实时交互中的总收益。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
- 将实时 RL 问题建模为**半马尔可夫决策过程 (SMDP)**，智能体在每个元决策点选择一个**预算选项（budgeted option）**，该选项决定了规划的模拟次数（即思考时长），并在执行完该选项后环境已推进了相应步数。
- 通过训练一个**轻量级门控策略 (gating policy)**，在**冻结的 AlphaZero 规划器**之上，依据当前状态自动选择最优规划预算，从而逃脱“规划如何规划”的无限递归。

### 关键技术细节
1. **实时交互协议**：环境每帧推进（无论智能体是否提交动作），智能体未提交时执行预设的**反射策略 (π_reflex)**——通常是规划器策略网络的一次快速前向。
2. **预算选项**：对每个离散预算 \(k \in K\)，定义选项 \(o_k\)：启动 MCTS 规划（运行 \(k\) 个环境的模拟帧），前 \(k-1\) 帧执行反射策略行动，最后一帧应用 MCTS 选出的精炼动作。该选项形成一个 SMDP 转移，元值函数的 Bellman 方程使用 \(\gamma^k\) 折扣。
3. **门控策略架构**：输入包括（a）原始游戏观测、（b）规划器中间空间特征（从冻结的 AlphaZero 骨干提取）、（c）规划器的标量价值估计 \(V(s_t)\)。在时钟环境中还包括剩余时间。轻量级网络输出动作分布和基线价值。
4. **训练**：两阶段——先训练 AlphaZero 基规划器（自对弈/专家迭代），冻结后，用 **PPO** 训练门控策略，并使用**变时长广义优势估计 (variable-duration GAE)** 处理元步长不等带来的折扣差异。
