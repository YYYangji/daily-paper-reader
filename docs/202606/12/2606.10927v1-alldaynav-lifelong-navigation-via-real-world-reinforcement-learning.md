## 摘要
动态环境中的终身具身导航要求机器人从片段化的观察中形成持久的场景理解，这对于现有依赖显式地图或场景图且难以在结构化环境之外泛化的方法而言仍然困难。我们提出AllDayNav，一种终身自学习导航框架，通过强化学习将场景动态隐式编码到大型模型的十亿级参数中，并配备自我演化的多模态记忆，该记忆维护和更新视觉关键帧、语义描述和时间上下文，同时自主生成开放词汇指令、图像目标和结构化奖励。在跨房间、跨回合和跨任务场景的合成与真实世界环境中的实验表明，AllDayNav的成功率接近100%，并在路径效率和鲁棒性方面持续超越基于地图、VLM和强化学习的强基线方法，证明了隐式、记忆驱动的强化学习作为可靠终身导航中显式映射的可扩展替代方案。

## Abstract
Lifelong embodied navigation in dynamic environments requires robots to form persistent scene understanding from fragmentary observations, which remains difficult for existing methods that rely on explicit maps or scene graphs and struggle to generalize beyond structured settings. We propose AllDayNav, a lifelong self-learning navigation framework that implicitly encodes scene dynamics into the billion-scale parameters of a large model via reinforcement learning, powered by a self-evolving multimodal memory that maintains and updates visual keyframes, semantic descriptions, and temporal context while autonomously generating open-vocabulary instructions, image goals, and structured rewards. Experiments in both synthetic and real-world environments across cross-room, cross-episode, and cross-task scenarios show that AllDayNav achieves success rates approaching $100\%$ and consistently surpasses strong map-based, VLM, and RL baselines in path efficiency and robustness, demonstrating implicit, memory-driven reinforcement learning as a scalable alternative to explicit mapping for reliable lifelong navigation.

## 2. 提出的方法论：核心思想、技术细节

### 2.1 核心思想
- **记忆-策略共进化**：自主构建自进化多模态记忆数据库，从中生成自指令和视觉目标，训练VLA策略，无需人类监督。
- 将导航目标表示为**视觉目标**（图像）而非符号指令，维护与这种表达一致的持久内部记忆。

### 2.2 系统架构（四个模块）

| 模块 | 功能 |
|------|------|
| **预训练VLA骨干** (Qwen2-7B) | 双编码器（SigLIP + DINOv2）提取语义和结构特征，融合后通过Transformer预测K=8个连续路径点。历史帧使用全局平均池化压缩 + 指数衰减注意力偏置。 |
| **自进化多模态记忆数据库** | 每条记忆为四元组 (图像, 语义描述, 时间戳, 视觉嵌入)。帧间相似度>0.15视为关键帧候选，与已有记忆相似度>0.7则更新冗余（保留与文本对齐更好的图像），否则插入新条目。 |
| **自指令生成与混合目标检索** | 每10回合或记忆增长20%时，用VLM (Qwen3-VL-8B-Instruct) 基于记忆描述生成50条多样化指令。对每条指令，先在记忆中检索目标图像（VLM选择），置信度<0.6或早期探索时退回互联网图像集。 |
| **保守Q学习（CQL）优化** | 状态：当前观测+目标图像+历史帧；动作：8个路径点。奖励=终止奖励(+10 if 相似度≥0.75) + 进度奖励(首次超过0.5/0.6/0.7时+2) + 时间惩罚(-0.01) + 碰撞惩罚(-0.1)。CQL损失：Bellman误差 + 对数求和惩罚项(α=5.0) 抑制Q值过估计。策略优化：Q值最大化 + 行为克隆正则化(λ=0.1) 防止遗忘。每100步更新一次。 |

### 2.3 训练流程（两阶段）
1. **离线预训练**：在Habitat模拟器中，使用HM3D+MP3D数据集（50,000条轨迹，500万步，80%专家轨迹+20%探索轨迹），加增强（模糊、噪声、裁剪等）弥合sim-to-real差距。优化MSE损失，14K步，batch 320，AdamW, lr=3.3e-5。
2. **在线自学习**：在新环境中，agent自主探索→更新记忆→生成自指令→混合检索目标→用CQL更新策略→循环。
