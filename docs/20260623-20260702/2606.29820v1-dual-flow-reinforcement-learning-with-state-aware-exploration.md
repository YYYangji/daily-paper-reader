## 摘要
在复杂的连续控制强化学习任务中，多模态最优动作往往伴随着不确定的多模态回报分布，使得可靠的价值估计和多模态探索具有挑战性。现有的使用单峰高斯分布的价值估计方法限制了表达能力并产生有偏估计。最近的生成式策略可以表示多模态动作，但通常会坍缩到少数几个模态，并对动作空间中高价值区域的探索不足。受这些挑战的启发，我们提出了Dual-Flow RL，一个统一的演员-评论家框架，利用条件流匹配（CFM）联合建模连续回报分布和多模态策略分布。这种设计支持可靠的价值估计和持续的多模态探索。为了进一步增强探索，我们引入了熵-协方差探索调节器（ECER），该调节器利用策略熵和动作不确定性协方差实现状态感知的探索调节。在DeepMind Control Suite和Humanoid-Bench上的实验表明，Dual-Flow RL在大多数任务上达到了最先进的性能，显著优于先前的基于扩散和基于流的方法。

## Abstract
In complex continuous-control reinforcement learning tasks, multimodal optimal actions often coincide with uncertain, multimodal return distributions, making reliable value estimation and multimodal exploration challenging. Existing value estimation methods using unimodal Gaussians restrict expressiveness and yield biased estimates. Recent generative policies can represent multimodal actions but often collapse to a few modes and under-explore high-value areas of the action space. Motivated by these challenges, we propose Dual-Flow RL, a unified actor-critic framework that jointly models a continuous return distribution and a multimodal policy distribution using conditional flow matching (CFM). This design supports reliable value estimation and sustained multimodal exploration. To further enhance exploration, we introduce an Entropy-Covariance Exploration Regulator (ECER) that enables state-aware exploration regulation leveraging policy entropy and action-uncertainty covariance. Experiments on DeepMind Control Suite and Humanoid-Bench show that Dual-Flow RL achieves state-of-the-art performance on most tasks, significantly outperforming prior diffusion-based and flow-based methods.

## 2. 方法论：核心思想、关键技术细节、公式或算法流程

### 核心思想
- 利用条件流匹配（Conditional Flow Matching, CFM）**联合建模** 连续回报分布（分布性评论家）与多模态策略分布（生成式策略）。
- 引入 **熵-协方差探索调节器（ECER）**，利用策略熵和动作不确定性协方差实现**状态自适应的闭环探索调控**。

### 关键技术细节

#### (1) 基于流的分布性评论家（Flow-based Distributional Critic）
- 对任意状态-动作对 (s,a)，将回报分布 Z(s,a) 建模为条件流：从基分布 z0~N(0,1) 出发，通过学习的速度场 v_z(s,a,z_t,t) 沿 ODE 演化到 t=1 得到回报样本 z1。
- **训练目标**：最小化流匹配损失，使 Z(s,a) 拟合一步 TD 目标分布 p_td(·|s,a)=r+γZ(s',a')。
- **理论保证**：当损失达到全局最小时，回报分布满足分布贝尔曼一致性（Proposition 4.3）。

#### (2) 基于流的策略（Flow-based Policy）与改进目标
- 同样通过 CFM 建模策略分布：从 a0~N(0,I) 经速度场 v_π(s,a_t,t) 生成动作 a_π=a1。
- **策略目标函数**（公式19）：包含两项——① 最大化均值价值 Q(s,a_π(s))；② 通过指数权重 w(s,a) 加权，引导策略分布向 replay buffer 中高价值动作对齐，保持多模态探索。

#### (3) 熵-协方差探索调节器（ECER）
- **核心机制**：对每个状态 s，学习一个探索尺度 σ_ψ(s) ∈ R^d_+，使执行动作 ae = a_π + σ(s)⊙ε（ε~N(0,I)），实现状态感知的噪声注入。
- **调节信号**：基于策略熵 H(s)（由拟合的 GMM 估计）和动作-不确定性协方差 ρ(s)（衡量动作密度集中区域与回报不确定性之间的相关性），构建两个门控 g_H, g_D，组合成全局门控 g = g_H·g_D，进而调节正则化系数 λ_eff = λ_0 / (g^2 + ε)。
- **训练目标**（公式24）：最大化增益加权对数似然（增益 Ae(s)=Q(s,ae)-Q(s,a_π(s))），同时惩罚过大的探索尺度。

#### 算法流程（Algorithm 1）
1. 每轮训练：与环境交互收集数据（由策略生成动作，ECER 添加探索噪声）。
2. 更新步骤：采样并依次更新评论家 θ、策略 φ、ECER 参数 ψ、目标网络。
3. 每 U 步更新门控与 λ_eff。

- **理论严谨**：证明了最优CFM速度场能实现分布贝尔曼一致性（Proposition 4.3）。
